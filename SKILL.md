# briefsnap

Morning briefing aggregator — one command pulls HN, RSS, Bluesky, GitHub, and arXiv into a single digest

## Install

```
pip install briefsnap
```

## Usage

```
briefsnap [TARGET] --limit 10 --output json
```

Formats: text, json, table, csv. Run `briefsnap introspect` for a machine-readable
description.
